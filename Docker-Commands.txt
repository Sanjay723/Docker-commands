
-> docker ps --- list running containers 
-> docker ps -a --- list all containers including exited
-> docker pull alpine 3.22.4 --- pull an image from docker registory (https://hub.docker.com)
-> docker images --- list the local pulled images
-> docker pull busybox:unstable-uclibc --- pull to local registry / system 
-> docker run image -- run a container
-> docker run -d image -- run container in background
-> docker run -p HOST:CONTAINER  -- Port mapping host to container
-> docker run -itd --name myapp01 -p 8080:80 nginx -- run nginx container in detached mode
-> docker inspect container_or_image --  Detailed Container/Image Information
-> docker exec -it <container-id> /bin/bash -- Login and access to container terminal
-> docker info --- docker engine details
-> docker rmi image_id --- remove a docker image
-> docker rmi -f image_id --- force remove docker image
-> docker stop container --- stop a running container
-> docker image/system prune -a --- remove all unused docker images
-> docker exec container-id ls --- list the directories in the container
-> docker exec container-id mkdir dir_name --- create a directory in the container
-> docker cp index.html container-id:/dir_name --- copy the file from home directory to specified directory
-> docker commit container-id image-name --- create a new docker image from a running or stopped container(custom clone,reusable)
-> docker save -o image.tar image-name:v1 --- saves docker image as a tar archive file for backup, transfer or sharing between systems.
-> docker load -i image.tar --- loads a docker image from a .tar archive file into local docker system
-> docker save alpine:latest -o alpine-lts.tar --- saves alpine docker image as a .tar archive file for backup or transfer.
-> docker image inspect alpine:latest --- displays detailed info about alpine docker image in JSON format.
-> docker history webapp-img:v1.0 --- shows the history and layers used to build the docker ima
-> docker tag alpine:latest alpine:ltsv1.0 --- creates a new tag/name for an existing Docker image version (retagging).
-> docker rename zealous_gates new_container --- renames existing docker container with a new container name.
-> docker push sanjaygovinds44/webapp-img:v1.1 --- push docker image from local system to the docker hub repository.
-> docker login -u <username> --- login into docker hub or docker registry.
-> docker diff container-id --- shows changes made to files and directories inside a container.
-> docker logs -f container-id --- displays and continuously follows live container logs.
-> docker stats --- shows real-time CPU, Memory and Network usage statistics of running containers.
